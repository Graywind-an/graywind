# 给人的说明书 · 一页

> **DSH 起不来的时候，双击桌面上的「复活」。**
> 它会列几个数字，你只要选一个。选错了不会更坏 —— 每个数字都写明「什么时候按」。
> 最后更新：2026-11-01

---

## 按数字

| 按 | 什么时候按 | 按下之后 |
|---|---|---|
| **1** | **刚重启就崩**，弹窗里写 `Web authentication failed` | 先清 cookie 再启动 DSH（最常见的一条，数据不会丢） |
| **2** | 界面弹出**三个选项**（重启 / 安全模式 / 禁用插件），三个都试过还是崩 | 降级启动：把插件配置清空再开。先让它能起来，插件以后一个一个加回来 |
| **3** | 主机打不开，但你还能打开镜像（镜像盘那份） | 开镜像里的 DSH，去修主机 |
| **4** | **主机和镜像都打不开**（最后手段） | 开「底线版」：镜像盘上那份旧程序 + 最小配置，跟主机完全分开 |
| **5** | 想把「受保护的文件」和崩溃日志**拷一份出来**给别人看 | 桌面上会多一个 `复活-日期时间` 文件夹 |
| **6** | DSH **能起来**，但你怕「少了什么」；或者起不来、想知道坏在哪一项 | 跑体检，出 9 项报告（见下一节） |
| **7** | 体检报告里**哪一项红了，只想修那一项**、别的都不动 | 写 `7` + 那项的两位编号，比如 `702` 只修程序本体、`706` 只修受保护文件 |
| **8** | DSH 起来后某个插件不见了、或报加载失败 | 从镜像里把插件库补回来（只补缺的，已有的默认不动） |
| **9** | 想看看会话里有没有兜圈子/刷屏 | 跑 stallguard 离线检查（独立脚本，不需要 DSH） |
| **00** | 你要**动手改受保护的文件**（比如改 CORE.md 那种） | 先解锁；改完再进来重新锁 |

**按 0 退出。**

> **3 和 4 有个前提**：它们都是「同一份程序、另一套配置」，Windows 只允许同时开一个 DSH。
> 所以**主机那个还开着的时候，按 3 或 4 会一闪就退**——那不是坏了，是它发现主机已经在了。
> 真要用的时候，主机本来就打不开、没在跑，它就能起来。

**7 的规矩**：只能修 `01` `02` `06` `07` 这四项（就是报告里写着「能修」的那几项）。
`00` `03` `04` `05` 只能看、不能自动修。想一次把能修的都修了，按 6 跑完体检，它自己会问你要不要补。

## 体检（按 6）出报告怎么读

会看到 9 行，每行一个固定编号，后面跟一个判定：

| 判定 | 意思 | 你要做什么 |
|---|---|---|
| **正常** | 这一项没事 | 什么都不用做 |
| **注意** | 有苗头，或者本来就这样（比如进程没开） | 知道就行 |
| **异常** | 这一项出问题了，但不一定起不来 | 看它下面那行说明；缺文件的话，跑完会问你要不要补（答 y 就补） |
| **致命** | 这一项坏了，DSH 起不来（或受保护文件没了） | **马上处理** |

九个编号记不住没关系，报告里每项自己写着「现状」和「说明」：

```
[00] DSH 进程        DSH 有没有在跑
[01] 程序本体        程序文件在不在、多大
[02] profile 配置    插件配置在不在
[03] 崩溃日志        崩过几次、最近一次什么时候（开头一行就是报错原文）
[04] 镜像            镜像盘那份备份全不全
[05] 底线版          最后手段能不能开（程序 + 最小配置齐不齐）
[06] 受保护文件      它们和 memory 在不在
[07] 保护区          备份里有没有那些文件的副本
[08] 纯净区          虚拟盘试验用的那份齐不齐（不是最后手段）
```

**自己不会修？不用会。** 把报告那一页（`复活\体检报告\体检-*.md`）交给 AI，说一句「按这个修」就够。

**想让电脑自己修**：体检跑完，它会问一句「要按『只补缺失、不动已有』补文件吗？」——
输入 **y** 回车，它就把**缺的**文件补回来（内容不一样的**不会**动，所以不会把你的东西盖掉）。
它说「这次没有写任何文件」，意思是**没有缺的东西可补**，不是坏了。

## 什么时候找 AI

**这几种情况别自己试，直接找 AI**：

- 体检里出现「致命」
- 按了 1 还是起不来
- 弹窗的报错跟 `Web authentication failed` 不一样
- 你要改 `CORE.md` / `AGENTS.md` / `JUDGMENT.md` / `WORLD.md` 里的任何内容

**找 AI 时给它三样**（都在本机，不用你手抄）：

1. `复活\体检报告\` 里最新的那份 `体检-*.md`
2. 弹窗原文（截图或者抄一行都行）
3. 什么时候开始的、开始之前你干了什么（装东西 / 升级 / 换驱动）

想给更多材料，就按 **5** 取保护区，把桌面上那个文件夹一起给它。

## 三条禁令（这几件别自己做）

1. **别删 `C:\Users\<你>\.dsh`** —— 会话和配置全在里面，删了就不是修，是重来。
2. **别重装 DSH** —— 重装解决不了 cookie 和插件的问题，反而可能把能用的版本换掉。
3. **别把镜像（镜像盘那份）同步成最新** —— 它落后才是它的用处：今天的坏更新不会把两个一起弄死。

## 还有一条给 AI 的规矩

**镜像里的任何改动不会回到主机。** 在镜像里修完，要带走的改动必须在主机里再做一遍。
在镜像里登录过，用完**退出登录**（别把登录状态留在副本里）。
