# 镜像任务书 · 主机 DSH 起不来时用

> **你现在跑在镜像里，不是主机。主机坏了，你是来修它的。**
> 这份是给「镜像里的 AI」看的：镜像里的记忆可能比主机旧（镜像是上一个确认点，不按天算），所以下面写全了。
>
> **装机时要改的**：零、一 两节里的 `<...>` 换成你自己的路径和当时的症状。其余照抄。

---

## 零、先搞清楚你在哪

| | 路径 |
|---|---|
| **你（镜像）** | DSH_HOME=`<X>:\复活镜像\dsh-home`，工作区=`<X>:\复活镜像\ws`，程序=`<X>:\复活镜像\app` |
| **主机（要修的）** | DSH_HOME=`<C>:\Users\<你>\.dsh`，工作区=`<工作区绝对路径>`，程序=`<C>:\Users\<你>\AppData\Local\Programs\DeepSeek Harness` |
| **复活包** | `C:\Users\<你>\Desktop\复活` |

**一条硬规矩**：**不要在镜像里干活。** 镜像里的任何改动**不会**回到主机。你在这里只做一件事 —— **把主机修好**。

---

## 一、发生了什么

> 主机的主人写一句现场情况（没写就自己去查）：

```
（症状 / 报错原文 / 什么时候开始的 / 之前干了什么）
```

**你要自己查清楚这三样**（别猜）：

1. **报错原文是什么？** —— 让主人把弹窗发你；或者看
   `%APPDATA%\@deepseek-ai\dsh-desktop\logs\crash-*.log` 最新一份的开头
2. **主机 cookie 库多大？**
   ```powershell
   (Get-Item "$env:APPDATA\@deepseek-ai\dsh-desktop\Network\Cookies").Length
   ```
   - **5 万字节以上** = 极可能 cookie 撑爆（崩溃原因清单第 1 条）
   - 约 2 万字节 = 空库，不是这个病
3. **主机的工作区还在不在？** —— 受保护文件（`CORE.md` / `AGENTS.md` / `JUDGMENT.md` / `WORLD.md`）和 `memory\` 是否都在

---

## 二、要求

- 主机 DSH **能起来**
- **会话能恢复** —— 不是要重新开始一段
- **主机文件一个不能丢**：受保护文件、`memory\`、会话、配置
- **修的过程中不许把主机搞得更坏** —— 动手前先备份；不确定就先问

---

## 三、按可能性排（从最安全开始）

1. **cookie 撑爆**（已验证过）：主机完全退出 → 删 `Network\Cookies`（连带 `-journal`/`-wal`/`-shm`）→ 启动。数据不丢。
   细节见 `复活\崩溃原因清单.md` 第 1 条。
2. **看日志**：`~\.dsh\notes\` 下的 `launcher-*.log`、`%APPDATA%\@deepseek-ai\dsh-desktop\logs\`。
   **报什么错查什么，别凭印象。**
3. **是不是刚更新过？** 是 → 用镜像的 `app\` 换回主机的程序（**先备份主机的程序目录**，只换程序、不碰数据）。
4. **配置被改坏？** → 主机 `~\.dsh\profiles\desktop\` 里的 `.bak-*` 就是这时候用的；或者在主机跑
   `复活\checkup.ps1 -Fix 02`（从镜像的 `dsh-home\profiles` 补回缺件）。
5. **都不行 → 上报**：查到了什么（每条指得出文件或命令输出）、试了什么、还差什么条件。
   **不许**自己重装、不许删 `~\.dsh`、不许格式化。

## 四、做好后怎么验收（一条都别跳）

| # | 验什么 | 怎么验 | 过了是什么样 |
|---|---|---|---|
| 1 | 主机 DSH 起来了 | `tasklist /FI "IMAGENAME eq DeepSeek Harness.exe"` | 有进程 |
| 2 | 界面对 | 让主人看一眼 | 会话列表在，不是空白 |
| 3 | 会话回来了 | 跟主人确认 | 能看到原来那段对话 |
| 4 | 受保护文件在 | `dir` 主机工作区的四个 `.md` + `memory` | 都在、都不是 0 字节 |
| 5 | 体检干净 | 主机跑 `复活\checkup.ps1 -NoPause` | 01/02/06/07 没有「致命/异常」 |
| 6 | 记忆在 | `dir <工作区>\memory\` | `日记.md`、`输入库\`、`判断\` 都在 |

**任何一条不过 → 没修好，别收尾。**

---

## 五、收尾

1. 报一句：修好了、症状是什么、改了哪几处（每处指得出路径）
2. **在镜像里退出登录** —— 你在这里登录过，登录态不能留在这个副本里
3. 关掉镜像 DSH
4. 写一笔修复记录（症状 / 根因 / 改了哪几处 / 验收结果）
5. 提醒主人：**镜像里的任何改动不会回流到主机** —— 要带走的，回主机里再做一遍

---

## 附：为什么镜像落后

如果镜像和主机一样新，**今天那个坏更新会把两个一起弄死** —— 那就真的没救了。

**落后 = 镜像不知道今天那个 bug。** 所以：**镜像里的东西不许「同步成最新」。它旧，才是它的用处。**
